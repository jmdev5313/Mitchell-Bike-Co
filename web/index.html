What to look for

  1. The activity log. Every tool call streams in live, with the MCP server it went to: catalog, work orders or procurement.
  2. Refusals in red. The shop's code, not the model, decides what's allowed. A part that doesn't fit the Customer's upgraded wheels is refused, and so is ordering before the Customer approves.
  3. The order plan. The Agent picks the supplier with the quote, because that choice sets the ready date. The shop places it the moment the Customer approves.
  4. History and badges. Each work order records who did what: the Agent, the Mechanic, the Customer, and the shop. What changed while you were away is marked new.
